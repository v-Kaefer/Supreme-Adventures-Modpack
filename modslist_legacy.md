# Legacy Modpack Reference

This file captures the legacy pack references that were mentioned in `modslist_review.md` and the current public ATM9 release metadata.

## Source Notes
- Technic SSP and Tekkit Classic are taken from the official Feed The Beast wiki pages for those packs.
- All the Mods 9 is taken from the official CurseForge pack page and public file pages for the current 1.20.1 release line.
- ATM9 exposes release-note mod names publicly, but not a clean full manifest on the page I could access, so that section records the named mods and pack metadata that are visible on the official pages.
